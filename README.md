# Simple To-Do App

A clean and beginner-friendly To-Do application built with React.js, JavaScript, HTML, CSS, and Bootstrap 5.

## Features

- Add, edit, delete, and complete tasks
- Search tasks
- Filter by All, Completed, and Pending
- Save tasks in localStorage
- Dark mode toggle
- Show task date and time
- Responsive Bootstrap navbar, cards, and buttons
- Empty message when no tasks are available
- Smooth hover effects and animations

## Folder Structure

```text
src/
  pages/
    TaskFlowPage.jsx
  styles/
    global.css
  assets/
    empty-state.svg
  App.js
  index.js
  main.jsx
```

## Setup

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production Build

```bash
npm run build
npm run preview
```

Bootstrap 5 and Bootstrap Icons are loaded from CDN links in `index.html`.
